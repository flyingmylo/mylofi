# 票根墙数据

每场演出一个 `.md` 文件（`_` 开头的文件不会发布），frontmatter 字段：

```yaml
---
title: 惘闻 Wang Wen        # 乐队 / 演出名（必填）
tour: 岁月鸿沟巡演          # 巡演或专场名（可选）
date: 2026-09-19           # 演出日期（必填，YYYY-MM-DD）
venue: 山丘 Livehouse      # 场地（必填）
city: 苏州                 # 城市（必填）
price: ¥180                # 票价（可选）
note: 一句话现场感受。       # 演出后写下的感受（可选，已演出的场次建议写）
---
```

- 票根编号（G-年份-序号）与「即将上演」状态由构建自动计算，不用手写
- 已演出的场次会盖上 LIVE 印章；日期在未来的场次显示「即将上演」
